TLP Mail Marker settings

Applies to messages composed in Thunderbird. All processing stays on this device.

Organisation profiles

Share approved levels, a default and the missing-classification rule with the browser extension. Profiles are editable presets, not administrator-enforced policy. Permissions are approved separately.








Original message checks
By default, checks use the subject and quoted text in the composer. Optional original-message access lets the add-on also read the message you are replying to or forwarding. It never stores that content.




Privacy
No telemetry, remote services or message-content storage. Settings are saved locally. Classification labels for open composers are kept only in session memory and removed when the composer closes.


TLP is a sharing protocol, not encryption or access control. This add-on is a composition aid.
